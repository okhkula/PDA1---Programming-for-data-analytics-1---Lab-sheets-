My lab exercises and homework for **Programming for Data Analytics 1** (Ajman University) — an introduction to Python and its core data tools.

## 🎯 Topics covered

- Python basics — variables, arithmetic, input/output and control flow
- Functions and the standard library (`math`, `random`, `datetime`, `string`)
- Lists, tuples, dictionaries and sets, including set operations and comprehensions
- Working with files — CSV and JSON
- First steps with **pandas**
